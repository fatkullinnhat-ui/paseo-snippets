# paseo-snippets

Paseo 0.12 的工作区 Explorer 片段库。片段保存在当前 Daemon 的本地 JSON 文件中，同一宿主机所有工作区共享；不修改用户输入的脚本内容。

## 使用

Agent 输入框上方的 `{}` 图标：手机与窄屏 Web 打开独立片段页，电脑打开工作区 Explorer 面板；手机页面只提供管理、变量预览和复制。

在 `{}` Snippets 面板新建片段，输入名称、分组及脚本。已有数据的第一个标签用作分组，其余标签保留并继续参与搜索。点击放大镜后在原工具栏搜索；`A↕` 可选名称正序、倒序或创建时间顺序。鼠标经过片段任意位置显示 Run/Paste，包含 `{{变量}}` 的片段还会显示跟随鼠标的变量提示。点击片段打开完整操作菜单：

- **Run**：将片段发给当前工作区上次聚焦的单个可见 Agent 对话；若聚焦的是终端，则写入当前终端并追加 Enter。
- **Paste**：在该 Agent 输入框插入但不发送；若聚焦的是终端，则原样写入当前终端但不额外追加 Enter。
- **在所有页面运行**：向当前工作区分屏中当前显示的所有 Agent 页面发送片段；不触碰终端和隐藏的 Agent 标签。
- **复制、编辑、删除**：对单个片段进行相应操作。顶部 `A↕` 正上方的删除按钮进入分组多选，可选择一组或多组，一次删除这些分组的全部片段；二次确认显示实际总数，包含搜索未显示的片段。分组的“X 个片段”后面的笔按钮打开完整分组编辑页，可批量修改分组名称，也可逐个编辑组内所有片段。改名遇到已有同名分组时会拒绝，不会意外合并。

`{{name}}` 是本插件的变量扩展，执行、粘贴或复制前填写，预览即最终命令；变量值原样替换，不转义也不检查脚本正确性。

Paseo 0.12 插件 SDK 没有暴露工作区可见标签与 Agent 草稿接口。桌面/Web 客户端通过可见标签与最后聚焦的 Agent 输入框或终端输入区定位单个目标；这是与 Paseo 0.12 页面结构绑定的适配，不是 SDK 承诺的稳定接口。无法确定目标时明确报错，绝不猜测或改发到隐藏会话。终端 Paste 使用原样写入：片段自身包含换行时，终端中的 Shell/REPL 仍可能立即执行这些行。移动端没有该 Web 页面结构，Run/Paste 和“在所有页面运行”不可用；片段管理、变量与复制仍可用。

## 本地验证

```powershell
npm install
npm run typecheck
npm test
paseo plugin ls
```

数据路径：`$PASEO_HOME/plugin-data/paseo-snippets/snippets.json`，未设置 `$PASEO_HOME` 时使用 `~/.paseo/plugin-data/paseo-snippets/snippets.json`。本地文件为明文；不要在片段中保存密钥。该插件不会同步到 Termius Vault。
